# Windrose Content Packs

Supplementary content packs for [Windrose MapDesigner](https://github.com/alas-poor-ophelia/windrose-md), an Obsidian plugin for TTRPG mapping.

## Available Packs

### Object Packs

| Pack | Author | Description |
|------|--------|-------------|
| **Classic Dungeons** | Bloated Blowfish | 42 dungeon object icons in a timeless top-down style— doors, stairs, furniture, traps, and more. |

### Fog of War

| Pack | Author | Description |
|------|--------|-------------|
| **Neutral Fog** | -- | A tileable fog of war texture. |

## Installing Packs

Packs can be installed directly from Windrose's settings:

1. Open Windrose Settings
2. Navigate to the relevant section (Object Sets, Fog of War, etc.)
3. Click "Browse Content Packs"
4. Select and install the pack you want

## Registry

The `registry.json` file is served via [jsDelivr CDN](https://cdn.jsdelivr.net/gh/alas-poor-ophelia/windrose-content-packs@latest/registry.json) for fast, reliable access from the plugin.
